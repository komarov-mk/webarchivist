# ВебАрхивист

Расширение для браузера Chrome (Manifest V3), автоматизирующее скачивание изображений и сканов из российских цифровых архивов и библиотек:

- **Яндекс.Архив** (ya.ru / yandex.ru/archive)
- **Госкаталог.рф** (goskatalog.ru)
- **Президентская библиотека** (prlib.ru)

Расширение не собирает и не отправляет никакие данные пользователя. Все сетевые запросы выполняются только к самим поддерживаемым сайтам — с вашими собственными cookie сессии (то есть скачивание доступно по тем же правам, что и в браузере вручную).

## Возможности

### Яндекс.Архив
- **Скачать текущую страницу** — оригинальный скан открытой страницы документа.
- **Скачать все страницы** — весь документ целиком (количество страниц определяется автоматически).
- **Скачивание диапазона** — укажите диапазон страниц (например, `5-20`); страницы скачиваются **в той же вкладке, без прерывания сессии**, поочерёдным открытием каждой страницы документа.
- **Два режима**: отдельными файлами или одним ZIP-архивом.
- **Визуальный прогресс** — индикатор с текущим этапом (открытие страницы → автоувеличение в боксе → скачивание → сборка ZIP) и процентами.
- **Отчёт о результате** — по завершении выводится итог: сколько страниц скачано, были ли ошибки и по каким именно страницам.
- **Имена файлов**: обрезаются только до 100 символов (90 внутри ZIP), при этом номер страницы в конце имени **всегда сохраняется** — файлы в архиве не перезаписывают друг друга.

Скачивание оригиналов работает через официальный `image-grant` API Яндекс.Архива (`POST /archive/api/image-grant` → временный токен → оригинал скана). Как резервный механизм используется перехват запросов `type=original` с автоматическим увеличением документа в боксе просмотра.

### Госкаталог.рф
- **Скачать все изображения лота** одним нажатием, с прогрессом и отчётом об ошибках.

### Президентская библиотека
- Скачивание текущей страницы и диапазона страниц.
- Изображение собирается из тайлов просмотрщика (diva) в единый JPEG; доступен режим ZIP.

### Общее
- Проверка обновлений расширения (сверка версии с манифестом на GitHub Pages).
- Уведомления браузера о завершении скачивания.

## Установка

1. Скачайте или склонируйте репозиторий:
   ```bash
   git clone https://github.com/komarov-mk/webarchivist.git
   ```
2. Откройте `chrome://extensions` в Chrome.
3. Включите **Режим разработчика** (переключатель в правом верхнем углу).
4. Нажмите **Загрузить распакованное расширение** и выберите папку репозитория.
5. Закрепите иконку «ВебАрхивист» на панели расширений.

Сборка не требуется — расширение работает «из коробки» (vanilla JS, без этапа сборки).

## Использование

1. Откройте страницу документа в поддерживаемом сервисе (например, документ в Яндекс.Архиве).
2. Нажмите на иконку расширения — попап определит сайт и покажет доступные действия.
3. Для Яндекс.Архива: нажмите «Скачать все страницы» или укажите диапазон и нажмите «Скачать диапазон»; при желании включите режим ZIP.
4. Наблюдайте за прогрессом в попапе; по завершении появится итог с информацией об ошибках (если были).

Во время скачивания диапазона не закрывайте вкладку документа — страницы открываются по очереди в текущей вкладке. Само скачивание управляется фоновым сервис-воркером, поэтому кратковременное закрытие попапа не прерывает процесс.

## Архитектура

Chrome MV3, без сборки и внешних зависимостей (кроме bundled-библиотеки [JSZip](https://stuk.github.io/jszip/)).

```
webarchivist/
├── manifest.json            # MV3-манифест, разрешения, content scripts
├── background.js            # Сервис-воркер: importScripts + роутер сообщений
├── contentScript.js         # Универсальный контентный роутер + авто-зум Яндекс.Архива
├── popup.html / popup.js    # Интерфейс попапа
├── jszip.min.js             # JSZip (bundled)
└── src/
    ├── shared.js            # Общие утилиты (sanitizeFilename, проверка URL и т.д.)
    ├── popup-config.js      # Конфигурация сайтов и текстов сообщений
    ├── popup-utils.js       # Хелперы попапа (статус, прогресс, сообщения, скачивание)
    ├── site-yandex.js       # Логика попапа для Яндекс.Архива
    ├── site-goskatalog.js   # Логика попапа для Госкаталога
    ├── site-prlib.js        # Логика попапа для Президентской библиотеки
    ├── background-yandex.js # Фоновая логика Яндекс.Архива (grant API, диапазоны, ZIP)
    ├── background-prlib.js  # Фоновая логика Президентской библиотеки (тайлы, JSON)
    ├── content-yandex.js    # Извлечение данных со страниц Яндекс.Архива
    ├── content-goskatalog.js# Извлечение изображений на Госкаталоге
    └── content-prlib.js     # Извлечение данных diva-просмотрщика
```

Ключевые принципы:

- **Фоновый сервис-воркер выполняет все сетевые операции**: credentialed-запросы к API сайтов, скачивание изображений, сборку ZIP (в background, чтобы большие сканы не проходили через messaging попапа) и сохранение файлов через `chrome.downloads`.
- **Попап только отправляет команды и показывает прогресс** (`chrome.runtime.onMessage` → фазы `yaRangeProgress`), поэтому состояние загрузки не теряется при закрытии попапа.
- **Контентные скрипты** извлекают метаданные страницы (название документа, число страниц, nodeId сканов) из DOM и `__NEXT_DATA__`.
- **Многоуровневые фолбэки**: например, число страниц Яндекс.Архива определяется по цепочке из четырёх источников (пагинация → `__NEXT_DATA__` → миниатюры → ссылки каталога).

## Разрешения

| Разрешение | Зачем |
|---|---|
| `webRequest` | Перехват запросов к API изображений (nodeId, токены) как резервный механизм |
| `downloads` | Сохранение файлов и ZIP-архивов |
| `tabs` / `activeTab` | Поочерёдное открытие страниц диапазона в текущей вкладке |
| `notifications` | Уведомления о завершении скачивания |
| host-разрешения (ya.ru, yandex.ru, goskatalog.ru, shm.ru, prlib.ru) | Credentialed-запросы к API сайтов из фонового воркера |
| `raw.githubusercontent.com` | Проверка обновлений |

## Разработка

- Проверка синтаксиса: `node --check <файл>.js`
- После изменения кода нажмите «Обновить» (↻) на карточке расширения в `chrome://extensions`.
- Версия задаётся в `manifest.json`; она же используется для проверки обновлений.
